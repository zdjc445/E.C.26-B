# 项目分工说明

## 角色与职责

| 角色 | 负责内容 | 交付物 |
| --- | --- | --- |
| 产品与演示 | 梳理赛事要求、定义 MVP 主链路、准备演示脚本 | 需求文档、演示说明、最终交付清单 |
| 后端工程 | Spring Boot API、鉴权、识别/搜索/refine/比价/推荐接口、数据隔离 | 可运行后端、OpenAPI、接口测试 |
| AI 工程 | Ark Provider 接入、mock 兜底、结构化识别与自然语言筛选解析 | AI Provider、Prompt、fallback 策略 |
| 前端工程 | Web/PWA 拍照上传、建议卡片、商品列表、对比表和推荐理由展示 | 可运行演示端 |
| 数据与测试 | mock/sample dataset、Flyway schema、主链路自动化测试 | mock 数据、数据库 schema、测试报告 |

## 协作边界

- `docs/00-比赛要求.md` 作为赛事原始要求归档，只读不改。
- 数据源只使用 `mock` / `sample_dataset`，真实平台仅保留 `official_api` 扩展口。
- Ark 密钥只通过环境变量读取，不进入仓库和文档明文。

## 当前实现状态

- 已完成可运行 Web/PWA + Spring Boot MVP。
- 已支持 mock 离线演示、Ark 可选接入、自然语言筛选回退、商品对比、推荐 evidence。
- PostgreSQL profile 下会把运行时核心记录写入 Flyway schema，默认 profile 保持内存运行，便于本机演示。
