## 答辩问答口径

评委可能从以下角度追问，答辩时按模块说明个人实现即可：

1. **「这个综合分怎么算的？」** → 回答 `RecommendationExplainer.weightedScore` 的权重分配（match 25% / price 25% / reputation 20% / channel 15% / risk 15%）。
2. **「Ark 失败时怎么保证演示不挂？」** → 说明意图解析与解释改写的回退链路与 `notices` 透传。
3. **「多轮筛选怎么记上下文？」** → 讲解 `MockAgent.mergeContext`，按「当前明确 > 历史最新 > 默认」的覆盖规则。
4. **「品牌 / 平台 / 排序怎么从一句话里抽出来的？」** → 演示 `UserPreferenceParser.parseBrand / parsePlatforms / parseSortBy / parseMinRating`。
5. **「Flutter 端的卡片渲染流程？」** → 按 `_buildCard` switch 解释 5 种 cardType 渲染逻辑。
6. **「商品对比/价格走势怎么画的？」** → 讲 `ProductItem.priceHistory` 和 `_PriceSparkline` CustomPainter。
7. **「样例数据为什么这么设计？」** → 说明从 20,000 行公开 CSV 中按精确关键词筛出 243 个基础商品，保留外部图片链接，再由代码生成四平台演示报价；评分、销量和品牌字段不完整，因此只验证筛选、分组和解释链路，不宣称真实推荐效果。
8. **「测试覆盖了什么？」** → 按测试文件逐条说明。
