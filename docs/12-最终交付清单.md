# 最终交付清单

## 已具备

- Spring Boot 后端可启动，Swagger UI 可访问。
- Web/PWA 演示端可运行，支持文件上传、浏览器相机拍照和示例图。
- 主链路覆盖：登录、拍照/上传、识别、建议卡片、自然语言筛选、排序、比价、商品对比、推荐理由。
- mock 商品、平台商品、历史价格、评价摘要和识别样例数据齐备。
- `official_api` 数据源已接入拼多多/京东官方 API 适配器，支持服务端签名、真实响应映射和本地 stub 集成测试。
- Flyway schema 覆盖用户、图片、识别、搜索、refine、比价、推荐、收藏和价格提醒。
- 自动化测试覆盖主链路、跨用户隔离、Ark 缺 Key 回退和官方 API 数据源映射。

## 演示前检查

1. 后端执行 `mvn test` 通过。
2. 后端执行 `java -jar target/shopping-agent-0.1.0.jar` 后访问 `http://localhost:8080/swagger-ui.html`。
3. 前端执行 `python -m http.server 5173 -d frontend` 后访问 `http://localhost:5173`。
4. 使用示例图或相机拍照完成一次识别。
5. 输入“1000 元以内的黑色款，要评价 4.8 分以上，只看官方”后列表刷新。
6. 勾选 2-4 个商品生成对比表，再生成 Agent 推荐。
7. 如需真实平台数据，配置 `ECOMMERCE_API_ENABLED` 和平台密钥后，将 Web 端“数据源”切换为“官方 API”。

## 可选增强

- 配置 Ark 环境变量启用真实 VLM/LLM。
- 配置拼多多或京东开放平台环境变量，联调真实商品搜索结果。
- 启用 `postgres` profile 验证服务端快照落库。
- 录制 3-5 分钟演示视频并按 `docs/08-演示说明.md` 脚本讲解。
