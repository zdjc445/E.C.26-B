# 数据库设计

## 设计原则

数据库设计以 [API 接口设计](04-API接口设计.md) 为主契约，支撑以下主流程：

```text
imageId -> recognitionId -> searchTaskId -> comparisonId -> recommendationId
```

约定：

- 数据库字段使用下划线命名，API JSON 字段使用小驼峰命名
- ID 使用 `bigint`
- 金额字段拆为 `*_amount` 和 `currency`
- 用户私有数据必须绑定 `user_id`，公共商品数据可以复用
- `match_score` 属于某次搜索任务结果，不属于平台商品固定属性

## 核心实体

```text
用户 users
用户会话 user_sessions
上传图片 uploaded_images
识别记录 recognitions
标准商品 products
平台商品 platform_products
价格记录 price_records
评价摘要 review_summaries
搜索任务 search_tasks
搜索任务结果 search_task_items
比价记录 comparisons
比价明细 comparison_items
推荐记录 recommendations
推荐证据 recommendation_evidence
收藏 favorites
价格提醒 price_alerts
```

## 数据归属规则

| 数据 | 是否用户私有 | 归属字段 |
| --- | --- | --- |
| users | 是 | id |
| user_sessions | 是 | user_id |
| uploaded_images | 是 | user_id |
| recognitions | 是 | user_id |
| search_tasks | 是 | user_id |
| search_task_items | 是 | user_id |
| comparisons | 是 | user_id |
| comparison_items | 是 | user_id |
| recommendations | 是 | user_id |
| recommendation_evidence | 是 | user_id |
| favorites | 是 | user_id |
| price_alerts | 是 | user_id |
| products | 否 | 无 |
| platform_products | 否 | 无 |
| price_records | 否 | 无 |
| review_summaries | 否 | 无 |

查询用户私有数据时，必须追加当前登录用户的 `user_id` 条件。前端不能传入 `userId` 决定数据归属。

## users

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 用户 ID |
| username | varchar | 登录用户名，唯一 |
| password_hash | varchar | 密码哈希，不存明文密码 |
| nickname | varchar | 昵称 |
| avatar_url | varchar | 头像地址 |
| status | varchar | 用户状态，active / disabled |
| last_login_at | datetime | 最近登录时间 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

建议约束：

```text
unique(username)
```

## platform_products

平台商品是跨平台归一化后的公共商品数据，不保存与某次搜索相关的 `match_score`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 平台商品 ID，对应 platformProductId |
| product_id | bigint | 关联标准商品 |
| platform | varchar | 平台编码，jd / taobao / pdd / tmall / other |
| title | varchar | 平台商品标题 |
| image_url | varchar | 商品图片 |
| price_amount | decimal | 当前价格 |
| original_price_amount | decimal | 原价或划线价 |
| currency | varchar | 币种，默认 CNY |
| url | varchar | 商品链接 |
| shop_name | varchar | 店铺名称 |
| source_type | varchar | mock / official_api / crawler |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

建议索引：

```text
index(product_id)
index(platform)
index(source_type)
```

## search_task_items

搜索任务结果保存某次搜索下的候选商品。`match_score` 放在这里，因为匹配分依赖本次搜索目标。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 搜索结果项 ID |
| user_id | bigint | 用户 ID |
| search_task_id | bigint | 搜索任务 ID |
| product_id | bigint | 标准商品 ID |
| platform_product_id | bigint | 平台商品 ID |
| match_score | decimal | 本次搜索下的同款或相关度分 |
| rank_index | int | 排序位置 |
| source_type | varchar | mock / official_api / crawler |
| created_at | datetime | 创建时间 |

建议约束：

```text
unique(search_task_id, platform_product_id)
```
