## 后端模块设计

```text
backend/src/main/java/com/ec26b/shoppingagent/
├── api/          # Health、Image、Chat、Recognition REST 控制器
├── ai/           # Mock/Ark/Fallback 识别 Provider 与识别结果
├── chat/         # ChatStore、历史仓库、MockAgent 与卡片响应
├── config/       # AI Provider 配置
├── image/        # 上传图片元数据内存存储
└── product/      # 多平台 Mock 商品源、意图解析、搜索结果、推荐评分与推荐解释
```

核心后端组件：

- `ChatController`：聊天会话、消息、历史、重命名和删除。
- `RecognitionController`：图片识别和识别结果修正。
- `MockAgent`：购物意图识别、追问、多轮上下文合并、识别 category 继承和商品推荐卡片生成。
- `MockProductSourceProvider`：运动鞋、耳机、吹风机的三平台 Mock 商品，支持预算和颜色过滤。
- `RuleBasedShoppingIntentParser` / `ArkShoppingIntentParser`：规则与 Ark 购物意图解析。
- `FallbackShoppingIntentParser`：Ark 意图解析不可用时回退规则解析。
- `RecommendationScorer`：根据价格、官方/自营、配送、评分、销量和预算生成规则评分。
- `RecommendationExplainer` / `ArkRecommendationExplainer`：生成综合分、决策信号、证据摘要、风险提示和商品胜因/不足。
- `FallbackRecognitionProvider`：Ark 不可用时回退 Mock。

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 客户端框架 | Flutter | Android APP |
| 状态管理 | Riverpod | 聊天状态、API 注入和测试替换 |
| 路由 | GoRouter | 首页、我的页面和占位页面 |
| 图片选择 | image_picker | 拍照与相册 |
| HTTP 调用 | http | REST 与 multipart 请求 |
| 服务端框架 | Spring Boot 3.4 | Java 后端 |
| 构建工具 | Maven | 后端依赖与测试 |
| AI Provider | Mock / Ark | 图片识别、意图解析和解释改写均保留回退路径 |
| 商品数据 | Mock Product Source | 三平台人工构造数据 |
| 数据格式 | JSON | REST API 与卡片契约 |

## 当前架构约束

- 聊天首页是主要入口，非独立搜索页。
- 商品推荐通过聊天消息接口返回，当前没有独立商品搜索 API。
- 聊天历史、图片元数据和识别结果当前使用内存结构。
- 上传文件保存到本地 `uploads/`。
- 当前不使用 SSE 或 WebSocket。
- 真实电商 API、真实认证和 Postgres 作为后续迭代。
