## 后端模块设计

```text
backend/src/main/java/com/ec26b/shoppingagent/
├── api/          # Health、Image、Chat、Recognition REST 控制器
├── ai/           # Mock/Ark/Fallback 识别 Provider、识别结果、ArkClient
├── chat/         # ChatStore、历史仓库（Memory + Postgres 桩）、MockAgent
├── config/       # AI Provider 配置（Mock vs Ark 切换）
├── image/        # 上传图片元数据内存存储
└── product/      # 多平台 Mock 商品源、意图解析、搜索结果、推荐评分与推荐解释
```

核心后端组件：

- `ChatController`：聊天会话、消息、历史、重命名和删除。
- `RecognitionController`：图片识别和识别结果修正。
- `MockAgent`：购物意图识别、动态建议卡、多轮上下文合并、识别 category 继承和商品推荐卡片生成。
- `MockProductSourceProvider`：5 品类 × 3 平台 × 4 商品（60 个）Mock 数据，支持预算/颜色/品牌/平台/最低评分过滤和 5 种排序。
- `RuleBasedShoppingIntentParser` / `ArkShoppingIntentParser`：规则与 Ark 购物意图解析，覆盖 11 个字段。
- `FallbackShoppingIntentParser`：Ark 意图解析不可用时回退规则解析。
- `RecommendationScorer`：根据价格、官方/自营、配送、评分、销量、预算、品牌、最低评分生成规则评分并记录命中偏好。
- `RecommendationExplainer` / `ArkRecommendationExplainer`：生成综合分、决策信号、证据摘要、风险提示和商品胜因/不足。
- `FallbackRecognitionProvider`：Ark 不可用时回退 Mock。
- `ArkClient`：统一封装 Ark Chat Completions 调用，含 JSON 抽取、markdown 剥离与 base URL 归一化。
- `ArkRecognitionProvider`：含 content-type 头字节归一化（JPEG/PNG 检测）。

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 客户端框架 | Flutter 3.22+ | Android APP |
| 状态管理 | Riverpod 2.x | 聊天状态、API 注入和测试替换 |
| 路由 | GoRouter | 首页、我的页面和占位页面 |
| 图片选择 | image_picker | 拍照与相册 |
| HTTP 调用 | http | REST 与 multipart 请求 |
| 自定义绘制 | CustomPainter | 价格走势 sparkline |
| 服务端框架 | Spring Boot 3.4 | Java 21 后端 |
| 构建工具 | Maven 3.9+ | 后端依赖与测试 |
| AI Provider | Mock / Ark (Doubao-Seed-2.0-lite) | 图片识别、意图解析和解释改写均保留回退路径 |
| 商品数据 | Mock Product Source | 5 品类 × 3 平台 × 4 商品 |
| 数据格式 | JSON | REST API 与卡片契约 |

## 当前架构约束

- 聊天首页是主要入口，非独立搜索页。
- 商品推荐通过聊天消息接口返回，当前没有独立商品搜索 API。
- 聊天历史、图片元数据和识别结果当前使用内存结构。`PostgresChatHistoryRepository` 已埋桩，未启用。
- 上传文件保存到本地 `uploads/`。
- 当前不使用 SSE 或 WebSocket。
- AI Provider 通过 `app.ai.provider` 属性切换；环境变量 `AI_PROVIDER`、`ARK_API_KEY`、`ARK_ENDPOINT_ID`、`ARK_BASE_URL`。
- 商品数据固定使用 `MockProductSourceProvider`，当前交付不调用真实电商接口。
- 真实认证和 Postgres 持久化作为后续迭代。
