# 系统架构草案

## 整体架构

```text
┌─────────────────────────────┐
│   Flutter Android Client    │
│  (Camera / UI / State)      │
└─────────────┬───────────────┘
              │ REST / JSON
              ▼
┌─────────────────────────────┐
│   Spring Boot API Server    │
│  (Controllers / Services)   │
└──────┬──────────┬───────────┘
       │          │
       ▼          ▼
┌──────────┐ ┌──────────┐
│ AI Layer │ │ Product  │
│ (Ark /   │ │ Sources  │
│ Mock)    │ │ (Mock /  │
└──────────┘ │ Official │
             │ API)     │
             └──────────┘
```

## 后端模块设计

```text
backend/src/main/java/com/ec26b/shoppingagent/
├── ShoppingAgentApplication.java   # Spring Boot 入口
├── api/                             # REST 控制器
│   └── HealthController.java        # 健康检查（本阶段）
├── service/                         # 业务服务层（预留）
├── ai/                              # AI Provider 抽象与实现（预留）
├── agent/                           # Agent 编排与决策（预留）
├── product/                         # 商品数据源适配（预留）
├── security/                        # 认证与授权（预留）
├── persistence/                     # 数据持久化（预留）
└── config/                          # Spring 配置（预留）
```

## 前端模块设计

```text
app/lib/
├── main.dart                        # 入口
├── app.dart                         # MaterialApp 配置
├── router/                          # GoRouter 路由
├── core/
│   ├── network/api_client.dart      # 后端地址配置
│   └── theme/app_theme.dart         # 主题与颜色系统
└── features/                        # 功能模块（占位）
    ├── auth/                        # 登录/注册
    ├── camera/                      # 拍照
    ├── recognition/                 # 识别结果
    ├── search/                      # 搜索结果
    ├── comparison/                  # 跨平台比价
    └── recommendation/              # 购买推荐
```

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 客户端框架 | Flutter 3.22+ | Android 平台 |
| 状态管理 | Riverpod | 响应式状态管理 |
| 路由 | GoRouter | 声明式路由 |
| 服务端框架 | Spring Boot 3.4 | Java 21 |
| 构建工具 | Maven | 依赖与构建管理 |
| AI 模型 | 火山引擎 Doubao | 通过 Ark API 调用 |
| 数据格式 | JSON | REST API 契约 |

## 当前阶段架构约束

- AI Provider 默认为 `mock`，返回占位数据
- 商品数据源默认为内存模拟数据
- 无数据库依赖（后续引入 Postgres + Flyway）
- 无认证层（后续引入 Spring Security + JWT）
- 前后端独立部署，通过 REST API 通信
