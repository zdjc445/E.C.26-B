# 需求分析

## 项目背景

用户在购物时经常遇到以下问题：

- 不知道图片中的商品叫什么
- 同款商品分散在多个平台，价格难以比较
- 标价和实际到手价不一致
- 不知道当前价格是否值得购买
- 很难从大量评价中判断商品风险
- 自然语言需求难以直接转化为可靠商品推荐
- 不同用户的图片、识别记录、搜索任务、收藏和推荐记录需要互相隔离

本项目希望通过 AI 识物、商品搜索、比价与 Agent 决策能力，帮助用户更快做出可信购物决策。

## 目标用户

- 想通过拍照快速找到商品的用户
- 需要跨平台比价的用户
- 希望了解历史价格走势的用户
- 想用自然语言描述需求并获得推荐的用户

## 核心用户故事

```text
作为用户，
我希望拍摄一个商品或输入购物需求，
系统能够识别商品、搜索同款、比较价格、分析历史趋势，
并基于证据链告诉我当前是否值得购买。
```

系统主流程：

```text
imageId -> recognitionId -> searchTaskId -> comparisonId -> recommendationId
```

## MVP 范围

第一阶段优先实现：

- 用户注册、登录与登录态保持
- 图片上传或拍照识物
- 商品关键词与类别识别
- 商品候选结果展示
- 跨平台价格展示
- AI 推荐理由和 evidence 证据链生成
- 使用 mock 商品、价格历史和评价摘要数据完成稳定闭环

暂缓实现：

- 自动下单
- 复杂优惠叠加计算
- 大规模真实电商数据接入
- 长周期价格监控通知

## 非功能需求

- 推荐结果必须可解释
- 价格与商品信息不能由大模型凭空编造
- 识别失败或置信度低时需要提示用户
- 用户上传图片需要注意隐私保护
- 不同用户之间的图片、识别记录、搜索任务、收藏、推荐记录必须隔离
- 前端不能直接传入 user_id 决定数据归属，后端必须从登录态解析当前用户
