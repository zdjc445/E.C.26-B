# 演示脚本

本文档面向 3-5 分钟答辩演示与评委本地复现路径。脚本以「打开 APP → 文字推荐 → 图片识别 → 自然语言追加筛选 → 历史恢复」为主线，覆盖赛题三大主链路：拍照识物、动态建议卡、自然语言追加筛选。

## 演示前准备

### 启动后端

```powershell
cd backend
mvn -DskipTests clean package
java -jar target/shopping-agent-0.1.0.jar
```

健康检查：

```powershell
curl http://localhost:8080/api/health
```

返回应包含 `"status":"ok"`、`"app":"shopping-agent"`、`"aiProvider":"mock"`（或 `"ark"`）。

### 启动 Flutter Android

模拟器：

```powershell
cd app
C:\flutter\flutter\bin\flutter.bat pub get
C:\flutter\flutter\bin\flutter.bat run -d emulator-5554 --dart-define=EC26B_API_BASE_URL=http://10.0.2.2:8080
```

USB 真机：

```powershell
adb reverse tcp:8080 tcp:8080
cd app
C:\flutter\flutter\bin\flutter.bat run -d <device-id> --dart-define=EC26B_API_BASE_URL=http://127.0.0.1:8080
```

### 切换 Ark Provider（可选）

```powershell
$env:AI_PROVIDER="ark"
$env:ARK_API_KEY="<赛事提供>"
$env:ARK_ENDPOINT_ID="<赛事提供>"
$env:ARK_BASE_URL="https://ark.cn-beijing.volces.com/api/v3"
```

未配置 Ark 时会自动回退 Mock，演示路径不中断。

## 演示主链路（约 5 分钟）

### Step 0 — 入场（10s）

- 打开 APP，停留在聊天首页。
- 旁白：「这是一款 AI 拍照识物 + 智能比价 + 自然语言追加筛选的聊天式购物 Agent，前端 Flutter Android，后端 Spring Boot，AI 走火山引擎 Ark，未配置时回退 Mock。」

### Step 1 — 文字购物意图（45s）

- 在底部输入：`我想买300以内的耳机，价格低一点`。
- 期望：返回 12 条 Mock 商品、平台比价（京东/拼多多/淘宝），推荐卡显示综合分、决策信号、证据摘要、风险提示、商品对比。
- 旁白要点：
  - 规则解析提取了「品类=耳机、预算=300、低价倾向」。
  - 推荐解释由 RecommendationExplainer 生成结构化摘要；启用 Ark 后由 ArkRecommendationExplainer 改写面向用户的文本，结构化分数与商品 ID 不变。
  - 商品卡显示「预算命中」「低价命中」等偏好命中徽章，并绘制近期价格走势 sparkline。

### Step 2 — 自然语言追加筛选（45s）

- 同一会话继续输入：`只看京东的，4.8分以上`。
- 期望：商品仅来自京东-mock，rating 全 ≥ 4.8。证据摘要新增「平台」「最低评分」字段。
- 旁白要点：
  - 多轮上下文合并：品类、预算、颜色、品牌、平台、排序、最低评分均跨轮累积。
  - 自然语言筛选共支持：预算、颜色、官方/自营、配送、低价、好评、销量倾向、品牌、平台、排序方式、最低评分。

### Step 3 — 排序切换（30s）

- 继续输入：`价格从低到高排序`。
- 期望：商品按价格升序排列；证据摘要显示「按价格从低到高排序」。
- 旁白要点：演示综合推荐 / 价格升降序 / 销量优先 / 好评率优先 / 综合推荐五种排序。

### Step 4 — 拍照识物（60s）

- 新建会话，点击图片按钮，选择运动鞋图片（建议预先放入相册）。
- 期望：弹出识别卡（mock 识别 category=运动鞋），动态建议卡片显示「查看同款低价」「只看官方旗舰店」「配送更快」「相似风格推荐」「筛选颜色/品牌/尺码」「查看历史价格走势」六个按钮。
- 旁白要点：
  - 动态建议卡根据识别 category 生成差异化选项（运动鞋/耳机/吹风机/背包/智能手表各不同）。
  - 识别卡支持「修正识别结果」入口，能修改类别、品牌、型号和自定义属性。

### Step 5 — 点击建议卡（30s）

- 点击「查看同款低价」。
- 期望：Agent 从历史识别卡继承 category=运动鞋，自动加上 `lowest_price` 偏好并按价格升序展示。

### Step 6 — 历史恢复（30s）

- 打开左上角历史抽屉，切换到上一段对话。
- 期望：完整恢复识别卡 / 商品列表卡 / 比价卡 / 推荐卡，包括综合分、决策信号、证据摘要、商品对比、Provider 状态徽章。

### Step 7 — 边界与回退（30s）

- 输入 `30以内的耳机`。
- 期望：商品列表与比价卡均为空占位（`暂无符合条件的商品` / `暂无可比价平台`），仍然返回稳定的两张卡。
- 切换到「我的」页面，展示阶段状态、接口状态、AI Provider、聊天历史存储。

## 最小功能验证用例集（评委复用）

| 用例 | 输入 | 期望输出 |
|------|------|----------|
| 文字购物 | `我想买300以内的耳机` | product_recommendation，价格 ≤ 300 |
| 品牌筛选 | `耐克的运动鞋` | 商品标题全部含「耐克」 |
| 平台筛选 | `只看京东的耳机` | 商品全部来自 `京东-mock` |
| 评分阈值 | `评分4.8以上的耳机` | 商品 rating 全 ≥ 4.8 |
| 价格升序 | `耳机价格从低到高` | 商品价格单调不减 |
| 销量优先 | `销量优先的运动鞋` | 商品销量单调不增 |
| 颜色追问 | `推荐耳机` → `只看300以内的黑色款` | 含「耳机」、价格 ≤ 300、含「黑色」 |
| 拍照识别 | 上传运动鞋图片 | 识别卡 + 动态建议卡（6 选项） |
| 识别修正 | 把品牌改为「耐克」 | 卡片即时更新 |
| 超预算 | `30以内的耳机` | 空商品 + 空比价占位 |
| 历史恢复 | 切换历史会话 | 卡片完整恢复 |
| 新品类 | `推荐背包` / `推荐智能手表` | 各返回 12 条 mock 商品 |
| Ark 回退 | 关掉 Ark Key 重试 | Provider 徽章显示「已回退规则处理」 |

## 录屏要点（3-5 分钟）

1. 屏幕共享展示真机或模拟器。
2. 演示顺序与上面 Step 0 → Step 7 一致。
3. 标注 Provider 徽章变化和回退提示。
4. 最后停留在「我的」页面展示阶段状态与接口状态。
