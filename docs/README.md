## 当前实现入口

- 后端工程：`backend/`
- Web/PWA 演示端：`frontend/`
- Flutter 移动端骨架：`app/`
- mock 数据：`mock-data/`
- 官方要求基线：`docs/00-比赛要求.md`

## 编写规范

- 每个文档保持“先结论、再细节”的结构
- 所有接口、数据结构和 Agent 输出尽量使用固定格式
- 重要设计变更需要同步更新相关文档
- MVP 阶段优先记录能支撑开发和演示的内容
- 涉及用户历史、收藏、图片、推荐记录和证据链的数据必须明确归属用户
