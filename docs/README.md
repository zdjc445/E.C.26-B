# 项目文档目录

该目录用于沉淀智能识物比价购物 AI APP 助手的需求、设计、实现与测试资料。

## 文档结构

| 文档 | 作用 |
| --- | --- |
| [00-比赛要求.md](00-比赛要求.md) | 记录赛事方课题要求、TRAE 配置说明、技术边界、时间线、交付物和答辩方式 |
| [01-需求分析.md](01-需求分析.md) | 描述项目背景、用户角色、核心需求和 MVP 范围 |
| [02-系统架构.md](02-系统架构.md) | 描述整体架构、模块划分、数据流和技术选型 |
| [03-Agent设计.md](03-Agent设计.md) | 描述购物决策 Agent 的目标、工具、流程和输出规范 |
| [04-API接口设计.md](04-API接口设计.md) | 约定前后端接口、请求参数、响应结构和错误码 |
| [openapi.yaml](openapi.yaml) | 机器可读 API 契约，用于后续前后端生成类型和契约测试 |
| [05-数据库设计.md](05-数据库设计.md) | 设计核心数据表、字段和关系 |
| [06-开发计划.md](06-开发计划.md) | 拆分迭代版本、任务优先级和里程碑 |
| [07-测试方案.md](07-测试方案.md) | 规划功能测试、AI 效果评估和演示测试样例 |
| [08-演示说明.md](08-演示说明.md) | 准备项目展示、答辩亮点和演示流程 |
| [09-用户认证与数据隔离.md](09-用户认证与数据隔离.md) | 设计登录注册、Token 鉴权、用户私有数据隔离和权限校验 |
| [10-项目分工说明.md](10-项目分工说明.md) | 说明角色分工、交付职责和只读/合规边界 |
| [11-AI使用总结.md](11-AI使用总结.md) | 总结 Ark/mock Provider、Prompt、fallback 和合规使用方式 |
| [12-最终交付清单.md](12-最终交付清单.md) | 汇总最终验收、演示前检查和可选增强项 |

## 当前实现入口

- 后端工程：`backend/`
- Web/PWA 演示端：`frontend/`
- mock 数据：`mock-data/`
- 赛事原始要求：`docs/00-比赛要求.md` 只读归档，不在实现过程中修改

## 编写规范

- 每个文档保持“先结论、再细节”的结构
- 所有接口、数据结构和 Agent 输出尽量使用固定格式
- 重要设计变更需要同步更新相关文档
- MVP 阶段优先记录能支撑开发和演示的内容
- 涉及用户历史、收藏、图片、推荐记录和证据链的数据必须明确归属用户
