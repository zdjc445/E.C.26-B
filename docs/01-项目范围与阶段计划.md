# 项目范围与阶段计划

## 项目定位

本项目是一款面向 C 端消费者的 AI 拍照识物与智能比价购物助手。客户端首页采用聊天式购物 Agent 交互，用户可以通过文字、图片和后续语音能力描述购物需求，系统以追问卡片明确偏好，并在信息足够后输出推荐卡片。

## 开发阶段总览

### 第一阶段：聊天式 Mock Agent 闭环阶段（当前阶段）

**目标：** 在工程骨架基础上，打通聊天式首页、图片上传、Mock Agent 追问和推荐卡片的最小演示闭环。

**交付物：**

- Spring Boot 服务保持可启动，并保留 `GET /api/health`
- 图片上传接口 `POST /api/images/upload`
- 聊天会话接口 `POST /api/chat/sessions`
- 聊天消息接口 `POST /api/chat/sessions/{sessionId}/messages`
- Flutter 首页改为聊天式购物 Agent 界面
- 底部固定输入栏，支持文字输入、图片添加和语音占位按钮
- Mock Agent 返回追问卡片与推荐卡片
- 文档、Mock 数据与接口契约保持一致

**不包含：**

- 真实 AI 服务调用
- 真实电商 API 接入
- 用户认证与授权
- 数据库持久化
- 真实语音识别
- 收藏与价格提醒
- 完整决策记录

### 第二阶段：真实识别与搜索链路（后续迭代）

**目标：** 在聊天式入口下接入真实图片识别和商品搜索能力。

- 集成 Ark AI Provider，实现图片识别
- 使用 Mock 商品数据完成搜索结果展示
- 将 Agent 追问选项映射为搜索筛选条件
- 支持搜索结果卡片和基础比价卡片
- 增加错误状态、加载状态和接口降级提示

### 第三阶段：完整购物决策能力（后续迭代）

**目标：** 完善跨平台比价、真实数据源和 Agent 推荐解释能力。

- 跨平台商品聚合
- 自然语言追加筛选
- Agent 推荐理由、证据摘要与评分矩阵
- Postgres 数据持久化
- 真实电商 API
- 用户认证
- 收藏与价格提醒
- 演示视频与答辩材料

## 时间线

- 第一阶段：聊天式 Mock Agent 闭环（当前阶段）
- 第二阶段：真实识别与搜索链路（后续迭代）
- 第三阶段：完整购物决策能力（后续迭代）
