# 项目范围与阶段计划

## 项目定位

本项目是一款面向 C 端消费者的 AI 拍照识物与智能比价购物助手。客户端首页采用聊天式购物 Agent 交互，用户可以通过文字或图片描述购物需求，系统通过识别、追问、比价和推荐卡片辅助用户做购买决策。

## 当前阶段：聊天式 AI 识别 + 多平台 Mock 推荐 + 7 维度自然语言筛选

**目标：** 在聊天式首页下形成可演示的「文字/图片输入 → AI/Mock 识别 → 偏好追问 / 自然语言追加筛选 → 多平台 Mock 商品 → 比价 → 推荐」的闭环，同时把推荐解释扩展到综合分、决策信号、证据摘要、风险提示、商品对比。

**已完成能力：**

- Spring Boot 后端服务、健康检查和统一响应结构
- 手机 USB 调试下的核心演示闭环
- Flutter Android 聊天首页、历史入口、我的入口和底部输入栏
- 图片上传、拍照/相册选择、本地预览
- 聊天会话创建、列表、历史读取、重命名、删除
- 图片识别接口、识别结果卡片和识别修正能力
- `MockRecognitionProvider`、`ArkRecognitionProvider`、`FallbackRecognitionProvider`
- `AI_PROVIDER=ark` 配置路径，Ark 不可用时回退 Mock
- `RuleBasedShoppingIntentParser`、`ArkShoppingIntentParser`、`FallbackShoppingIntentParser`
- `CategoryResolver` 轻量 taxonomy 检索归一，支持细分品类映射到标准品类
- 多轮自然语言追加筛选：继承历史文本品类、识别卡 category、预算、颜色、品牌、平台、排序、最低评分
- 推荐解释增强：综合分、决策信号、证据摘要、风险提示、商品胜因/不足
- 多平台 Mock 商品数据源：`京东-mock`、`拼多多-mock`、`淘宝-mock`
- 5 个 Mock 品类（共 60 个商品，11 个品牌）：运动鞋、耳机、吹风机、背包、智能手表
- 商品列表卡（含品牌徽章、偏好命中徽章、价格走势 sparkline）
- 平台比价卡（含最低价 + 均价 + 平台亮点）
- 推荐购买卡（含综合分、五维决策信号进度条、证据摘要、风险提示、商品对比、Provider 状态）
- 动态建议卡：按识别 category 生成差异化建议入口
- 超预算/筛选过严时空商品卡 + 空比价卡占位
- 历史会话恢复完整 `agentReply` 卡片
- 后端 134 条 + Flutter 23 条自动化测试覆盖核心流程

**当前边界：**

- 真实 AI 识别需要配置 Ark 后继续实测，不默认保证外部服务可用。
- Ark 购物意图解析和推荐解释改写需要配置 Ark 环境变量；未配置或调用失败时回退规则解析与规则解释。
- 商品搜索和比价固定来自 Mock 数据，不调用真实电商接口，不代表真实平台商品、价格或库存。
- 真实认证、Postgres 落地、真实语音识别、收藏、价格提醒仍为后续迭代。
- 当前 Agent 输出结构化解释摘要，不输出真实模型推理链。
