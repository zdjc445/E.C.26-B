# 项目范围与阶段计划

## 项目定位

本项目是一款面向 C 端消费者的 AI 拍照识物与智能比价购物助手。用户通过摄像头采集商品图像，服务端完成商品识别后，动态生成导购建议卡片，支持跨平台商品匹配、自然语言追加筛选与购买决策辅助。

## 开发阶段总览

### 第一阶段：工程骨架与核心流程设计（当前阶段）

**目标：** 搭建前后端项目骨架，确立架构边界，完成核心流程设计文档。

**交付物：**

- Spring Boot 最小可启动服务 + `GET /api/health`
- Flutter Android APP 可启动 + 各功能模块占位页面
- 完整文档体系（架构草案、API 草案、AI/Agent 设计草案、测试计划）
- Mock 数据策略与极少量示例数据
- 工程目录结构与构建配置就绪

**不包含：**

- 真实 AI 服务调用
- 真实电商 API 接入
- 用户认证与授权
- 数据库持久化
- 完整业务功能闭环

### 第二阶段：核心链路打通（后续迭代）

**目标：** 实现"拍照 → 识别 → 搜索 → 建议"最小闭环。

- 集成 Ark AI Provider，实现图片识别
- 实现商品搜索 API（mock 数据）
- 实现建议卡片生成
- Flutter 客户端对接后端 API
- 登录/注册功能

### 第三阶段：完整功能交付（后续迭代）

**目标：** 实现所有核心功能并准备答辩。

- 跨平台比价聚合
- 自然语言追加筛选（AI 驱动）
- Agent 购买推荐与证据链
- Postgres 数据持久化
- 真实电商 API（拼多多、京东）
- 收藏与价格提醒
- 演示视频录制

## 时间线

- 第一阶段：骨架搭建（1-2 天）
- 第二阶段：核心链路（后续迭代）
- 第三阶段：完整交付（后续迭代）
