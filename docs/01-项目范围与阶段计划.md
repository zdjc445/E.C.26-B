# 项目范围与阶段计划

## 项目定位

识价镜是一款面向 C 端消费者的 AI 拍照识物与智能比价购物助手。客户端首页采用聊天式购物 Agent 交互，用户可以通过文字或图片描述购物需求，系统通过识别、追问、同款分组、平台报价和推荐解释辅助用户做购买决策。

## 当前阶段：聊天式 AI 识别 + 公开样例数据多平台比价 + 7 维度自然语言筛选

**目标：** 在聊天式首页下形成可演示的「文字/图片输入 → AI/Mock 识别 → 偏好追问 / 自然语言追加筛选 → 公开样例商品检索 → 多平台样例报价 → 同款分组 → 推荐」的闭环，同时把推荐解释扩展到综合分、决策信号、证据摘要、风险提示、商品对比。

**已完成能力：**

- Spring Boot 后端服务、健康检查和统一响应结构
- 手机 USB 调试下的核心演示闭环
- Flutter Android 聊天首页、历史入口、我的入口和底部输入栏
- 底部输入栏状态优化：空输入禁用发送、图片上传中禁用发送、输入聚焦态和触控区优化
- 图片上传、拍照/相册选择、本地预览
- 聊天会话创建、列表、历史读取、重命名、删除
- 图片识别接口、识别结果卡片和识别修正能力
- `MockRecognitionProvider`、`ArkRecognitionProvider`、`FallbackRecognitionProvider`
- `AI_PROVIDER=ark` 配置路径，Ark 不可用时回退 Mock
- `RuleBasedShoppingIntentParser`、`ArkShoppingIntentParser`、`FallbackShoppingIntentParser`
- `CategoryResolver` 轻量 taxonomy 检索归一，支持细分品类映射到标准品类
- 多轮自然语言追加筛选：继承历史文本品类、识别元数据 category、预算、颜色、品牌、平台、排序、最低评分
- 本地商品检索链路：`ArkQueryDecomposer`、`QueryRewriter`、`ProductVectorIndex`、`HybridRetriever`、`ResultReRanker`
- 推荐解释增强：综合分、决策信号、证据摘要、风险提示、商品胜因/不足
- 默认商品源 `public-dataset-platforms`：基于 `backend/src/main/resources/data/public-product-offers.json` 的公开样例商品数据生成多平台报价
- 保留 `mock-data/mock-data.json` 作为可切换的本地演示商品源
- 多平台样例报价生成：`京东-mock`、`淘宝-mock`、`天猫-mock`、`拼多多-mock`
- 商品分组卡（含品牌徽章、偏好命中徽章、价格走势 sparkline）
- 同款商品分组卡（含跨平台价格区间、最低价、评价/销量、平台报价明细）
- 商品详情页（含购买判断、平台角色标签、推荐点、价格走势和价格提醒入口）
- 动态建议卡：按识别 category 生成差异化建议入口
- 超预算/筛选过严时空商品分组占位
- 历史会话恢复完整 `agentReply` 卡片
- 后端 142 条自动化测试覆盖核心流程；Flutter 39 条 widget 测试覆盖当前 `profile` 参数、商品分组 UI、筛选编辑、收藏、详情页、价格提醒、底部输入栏和用户记忆入口

**当前边界：**

- 真实 AI 识别需要配置 Ark 后继续实测，不默认保证外部服务可用。
- Ark 购物意图解析和推荐解释改写需要配置 Ark 环境变量；未配置或调用失败时回退规则解析与规则解释。
- 商品搜索和比价默认使用公开样例商品数据并生成平台样例报价，不调用真实电商接口。样例报价不代表真实平台商品、价格、库存或评价。
- 认证、收藏和价格提醒具备演示链路；默认仍使用内存存储，Postgres 持久化需要显式启用 `postgres` profile。
- 真实语音识别仍为后续迭代；当前语音转写默认使用 Mock Provider。
- 当前 Agent 输出结构化解释摘要，不输出真实模型推理链。
