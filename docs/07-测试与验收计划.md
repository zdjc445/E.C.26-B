### 端到端验收

| 用例 | 操作路径 | 验收标准 |
|------|----------|----------|
| 拍照识物 | 拍照 → 上传 → 查看识别结果 | 识别结果准确展示 |
| 建议卡片 | 查看建议卡片 → 点击卡片 | 正确创建搜索任务 |
| 自然语言筛选 | 输入筛选条件 → 提交 | 结果列表正确过滤 |
| 跨平台比价 | 选择 2-4 商品 → 比价 | 多平台价格正确展示 |
| Agent 推荐 | 请求推荐 → 查看结果 | 决策信号与证据链展示 |

### 验收标准

- 主链路端到端无阻塞错误
- API 响应时间 < 5s（含 AI 调用）
- Flutter 静态分析 0 错误
- 后端所有测试通过
