## 手工验收路径

### 文字推荐

1. 启动后端和 Flutter APP。
2. 输入 `我想买300以内的耳机，价格低一点`。
3. 确认返回商品列表卡、比价卡和推荐卡。
4. 确认平台为 `京东-mock`、`拼多多-mock`、`淘宝-mock`。

### 图片识别推荐

1. 点击图片按钮，选择拍照或相册。
2. 确认图片预览和上传成功。
3. 确认返回识别卡和追问卡。
4. 点击 `价格最低`。
5. 确认 Agent 根据识别 category 返回商品推荐。

### 历史恢复

1. 完成一次商品推荐。
2. 打开左上角历史入口。
3. 切换会话。
4. 确认商品卡、比价卡、推荐卡可恢复。

### 超预算

1. 输入 `50以内的耳机`。
2. 确认返回空商品占位和空比价占位。

### Ark 实测

1. 配置 `AI_PROVIDER=ark`、`ARK_API_KEY`、`ARK_ENDPOINT_ID`。
2. 上传真实商品图片。
3. 确认 `aiProvider` 为 `ark` 且 `fallbackUsed=false`。
4. 故意移除 Ark 配置后重试，确认回退 Mock。

## 验收标准

- 后端测试通过。
- Flutter 静态分析无 error/warning。
- Flutter 测试通过。
- 真机或模拟器能完成文字推荐、图片识别推荐、历史恢复和超预算空状态。
- 手机 USB 调试路径可用于现场演示。
- Mock 数据不被描述为真实平台结果。
- 未接入能力有明确占位或后续说明。
