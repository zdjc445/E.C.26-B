## 手工验收路径

参考 [09-演示脚本.md](09-演示脚本.md) 中的最小功能验证用例集（13 条）。

### 文字推荐

1. 启动后端和 Flutter APP。
2. 输入 `我想买300以内的耳机，价格低一点`。
3. 确认返回商品分组卡和动态建议卡。
4. 确认平台报价来自 `京东-mock`、`淘宝-mock`、`天猫-mock`、`拼多多-mock` 中的一个或多个。

### 自然语言多维度筛选

1. 输入 `耐克的运动鞋`。
2. 确认商品标题全部含「耐克」。
3. 继续输入 `只看京东的`。
4. 确认商品分组内的平台报价全部为 `京东-mock`。
5. 继续输入 `4.8分以上`。
6. 确认商品 rating 全 ≥ 4.8。
7. 继续输入 `价格从低到高`。
8. 确认商品价格单调不减。

### 图片识别推荐与动态建议

1. 点击图片按钮，选择拍照或相册。
2. 确认图片预览和上传成功。
3. 确认返回带识别元数据的商品分组卡和动态建议卡（按 category 显示 6 个选项）。
4. 点击 `查看同款低价`。
5. 确认 Agent 根据识别 category 返回商品推荐。

### 多轮追加筛选

1. 输入 `推荐耳机`。
2. 继续输入 `只看300以内的黑色款`。
3. 确认返回商品仍为耳机，价格 ≤ 300，命中黑色。

### 历史恢复

1. 完成一次商品推荐。
2. 打开左上角历史入口。
3. 切换会话。
4. 确认商品分组卡、平台报价、动态建议卡、Provider 徽章均可恢复。

### 超预算

1. 输入 `50以内的耳机`。
2. 确认返回空商品分组占位和动态建议卡。

### Ark 实测

1. 配置 `AI_PROVIDER=ark`、`ARK_API_KEY`、`ARK_ENDPOINT_ID`。
2. 上传真实商品图片。
3. 确认 `aiProvider` 为 `ark` 且 `fallbackUsed=false`。
4. 故意移除 Ark 配置后重试，确认回退 Mock 并显示「已回退规则处理」徽章。
