### 后端

测试框架：

- JUnit 5
- Spring Boot Test
- MockMvc

当前阶段已覆盖：

- `GET /api/health` 返回正常状态
- `POST /api/images/upload` 正常上传返回 `imageId`
- 空文件上传返回错误响应


## 手工验收路径

1. 启动 Spring Boot 服务
2. 启动 Flutter Android APP
3. 进入首页，确认页面为聊天式购物 Agent
4. 输入购物需求并发送
5. 确认助手返回追问卡片
6. 点击追问选项
7. 确认助手返回推荐卡片
8. 添加图片并确认本地预览和上传流程可用
9. 点击语音按钮，确认只显示占位提示
