# 核心流程设计

## 主链路流程

```text
用户拍照 → 上传图片 → AI 识别商品
    → 展示识别结果 + 建议卡片
    → 用户选择建议卡片 / 输入自然语言筛选
    → 跨平台商品搜索
    → 展示搜索结果列表
    → 用户选择商品比价 → 展示多平台价格对比
    → 用户请求推荐 → Agent 分析后给出购买建议
```

## 详细流程说明

### 1. 拍照与上传

1. 用户在 APP 内打开相机，拍摄商品照片
2. APP 将图片上传至服务端 `POST /api/images/upload`
3. 服务端保存图片并返回图片 ID

（本阶段为占位，后续迭代实现）

### 2. 商品识别

1. 服务端将图片发送至 AI Provider（Ark / Mock）
2. AI 返回商品类目、关键属性（品牌、颜色、款式等）
3. 服务端基于识别结果生成建议卡片：
   - "查看同款低价"
   - "只看官方旗舰店"
   - "相似风格推荐"
   - "筛选：颜色/品牌/尺码"

（本阶段为占位，后续迭代实现）

### 3. 商品搜索

1. 用户点击建议卡片或输入自然语言筛选条件
2. 服务端调用商品数据源（Mock / Official API）搜索
3. 返回商品列表，包含：商品图、名称、价格、平台、标签

（本阶段为占位，后续迭代实现）

### 4. 跨平台比价

1. 用户在搜索结果中选择 2-4 个商品
2. 服务端聚合多平台同款商品信息
3. 展示各平台最低价、均价、对比表格

（本阶段为占位，后续迭代实现）

### 5. Agent 推荐

1. 用户请求购买推荐
2. Agent 分析候选商品，考虑价格、平台、评价等多维度
3. 输出决策信号、决策轨迹与证据链

（本阶段为占位，后续迭代实现）

### 6. 自然语言追加筛选

1. 用户在搜索框输入自然语言条件
2. 服务端通过 AI（Ark / 规则兜底）解析筛选意图
3. 刷新搜索结果列表

（本阶段为占位，后续迭代实现）
