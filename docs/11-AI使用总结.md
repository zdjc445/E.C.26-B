# AI 使用总结

## 使用位置

- 图片识别：后端读取用户上传图片，Ark VLM 可选生成类目、品牌、型号、关键词、属性和置信度。
- 自然语言 refine：Ark LLM 可选把用户追加条件解析为结构化 filters。
- 购物推荐：服务端基于候选商品、价格历史、评价摘要和匹配分生成可解释推荐。

## Provider 与兜底

- 默认 `AI_PROVIDER=mock`，无需外部 Key 即可完整演示。
- 设置 `AI_PROVIDER=ark` 且提供 `ARK_API_KEY`、`ARK_ENDPOINT_ID`、`ARK_BASE_URL` 后启用 Ark。
- Ark 未配置、超时、返回非 JSON 或字段非法时，识别回退 mock，refine 回退规则解析。
- 所有 AI 输出进入白名单校验，前端只消费后端返回的结构化结果。

## Prompt 输出约束

图片识别要求 Ark 只返回 JSON：

```json
{
  "category": "吹风机",
  "brand": "MockCare",
  "model": "HD-001",
  "keywords": ["低噪音", "宿舍"],
  "attributes": { "color": "黑色", "scenario": "宿舍" },
  "confidence": 0.86,
  "explanation": "根据图片外观和文字标识判断"
}
```

自然语言 refine 要求 Ark 只返回 JSON：

```json
{
  "filters": {
    "maxPrice": "1000.00",
    "color": "黑色",
    "minRating": 4.8,
    "officialOnly": true,
    "sortBy": "rating_desc"
  },
  "notices": []
}
```

## 合规说明

- 不在前端执行 AI 密钥调用。
- 不保存 Ark API Key。
- 不实现非授权数据抓取。
- 比赛演示使用 mock/sample dataset，真实平台数据只通过授权 API 扩展。
