# 演示说明

## 项目一句话介绍

拍一下商品，AI 帮你识别它、比较候选平台价格、判断历史价格是否划算，并基于证据链给出可信购买建议。

## 演示主流程

```text
imageId -> recognitionId -> searchTaskId -> comparisonId -> recommendationId
```

## 演示流程

1. 用户登录 APP
2. 上传或拍摄商品图片，获得 `imageId`
3. 创建识别任务，展示 `recognitionId`、类别、关键词和置信度
4. 输入自然语言需求并创建搜索任务，获得 `searchTaskId`
5. 展示 mock 平台候选商品、平台来源、价格和 `matchScore`
6. 创建比价，展示 `comparisonId`、最低价和价格排序
7. 查看平台商品历史价格趋势和评价摘要
8. 创建 Agent 推荐，展示 `recommendationId`、推荐结论、风险和 `evidence`
9. 收藏推荐商品或创建价格提醒

## 推荐演示场景

```text
用户拍摄一个吹风机，
并输入：帮我找 500 元以内，适合宿舍用，噪音小一点，售后靠谱的款。
```

系统应展示：

- 商品识别结果和置信度
- 多平台 mock 候选商品
- 候选商品的 `matchScore`
- 当前价格和历史价格趋势
- 评价摘要与风险标签
- Agent 推荐结论
- 推荐理由对应的 `evidence` 证据链

## 项目亮点

- 从“商品搜索”升级为“购物决策 Agent”
- 支持图片和自然语言两种输入
- 搜索、比价和推荐通过 `searchTaskId` 串联，过程可追溯
- Agent 不相信前端传入价格，而是读取后端可信商品数据
- 推荐结果包含 `evidence`，避免只给一句空泛结论
- MVP 使用 mock 数据稳定演示，后续可扩展官方 API 或合规采集
