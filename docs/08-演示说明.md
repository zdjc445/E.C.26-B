# 演示说明

## 项目一句话介绍

拍一下商品，AI 帮你识别它、生成下一步导购建议、跨平台比较候选价格，并通过自然语言追加筛选、商品洞察和证据链快速收敛到可信购买建议。

## 本机演示入口

```text
后端：http://localhost:8080
Swagger：http://localhost:8080/swagger-ui.html
前端：http://localhost:5173
```

启动方式见根目录 `README.md`。

## 快速兜底路径

Web/PWA 左侧图片区域提供“一键演示主链路”。点击后会自动登录或注册演示账号，载入示例图，完成识别、商品洞察、比价、Agent 推荐、收藏和价格提醒；左侧“主链路进度”会实时标记账号、识别召回、商品洞察、跨平台比价、Agent 决策和资产沉淀，顶部“决策摘要”会沉淀推荐结论、分数、最低价、风险和可复制答辩摘要，适合录屏前确认链路状态或现场网络/操作紧张时兜底。

录屏前可先运行真实浏览器烟测：

```powershell
python scripts\run-web-demo-smoke.py --scenario headphones
```

该脚本会打开 Web/PWA，选择耳机场景，点击“一键演示主链路”，并断言 6 步进度、3 个候选、比价表、商品洞察、5 类决策信号、6 步决策轨迹、候选胜因/败因矩阵、evidence 和收藏/价格提醒都已渲染；同时验证推荐证据报告接口、service worker 已激活、PWA app shell cache 已创建。

## 标准操作路径

1. 打开 Web/PWA 演示端。
2. 注册或登录账号。
3. 点击“打开相机”完成浏览器相机预览，也可以在“演示场景”中选择吹风机、耳机、手机、键盘、水杯、运动鞋或护肤乳，再点击“示例图”生成对应 mock 图片。
4. 点击“上传并识别”，展示类目、品牌、关键词、属性和置信度。
5. 查看动态建议卡片，如“查看同款低价”“只看官方旗舰店”“评价 4.8 分以上”。
6. 点击“只看官方旗舰店”或输入自然语言筛选：

```text
1000 元以内的黑色款，要评价 4.8 分以上，只看官方
```

7. 切换综合、低价、销量、好评排序，观察推荐列表刷新。
8. 点击商品卡“洞察”，展示 90 天价格走势、历史低点、评价摘要、正向标签和风险标签。
9. 点击“提醒”设置目标价，再点击“收藏”演示个性化入口和用户资产沉淀。
10. 点击左侧“历史工作台”的“搜索”，恢复刚才或过往的搜索任务，说明候选、识别结果和摘要可以回到主工作区；点击“图片”可查看上传图片历史并删除无用图片。
11. 勾选 2-4 个商品并点击“生成比价”，展示平台最低价、平台均价、平台商品数和横向商品对比表。
12. 点击“生成推荐”，展示 Agent 决策分、六步决策轨迹、候选胜因/败因矩阵、建议购买/观望/避开、理由、风险和 evidence。
13. 点击顶部“复制报告”，说明报告由服务端根据推荐记录、搜索任务、信号、轨迹、候选矩阵和 evidence 生成，可直接放入答辩材料或复盘记录。

## 推荐演示话术

```text
这不是单纯的以图搜图，而是把“识别 - 检索 - 比价 - 决策”串成一条可解释链路。
用户拍照后，服务端识别商品属性并生成建议卡片；用户可以点击卡片，也可以继续输入自然语言条件。
系统会把“1000 元以内、黑色、评分 4.8 以上、官方渠道”等条件结构化，刷新商品列表并重新计算平台统计。
商品卡上的洞察会调用历史价格和评价摘要接口，目标价提醒和收藏都归属于当前登录用户。
最终 Agent 不相信前端传入价格，而是基于后端 mock 数据、历史价格、评价摘要和匹配分生成带 evidence 的推荐，同时输出 `decisionScore`、五类 `decisionSignals`、六步 `decisionTrace` 和 `candidateAnalyses` 胜因/败因矩阵；前端只负责把这些结构化信号可视化，并可一键复制后端生成的 Markdown 证据报告。
```

## 兜底说明

- 默认 AI provider 为 `mock`，无 Ark API Key 时仍可完整演示；启用 Ark 后，接口会返回 provider 与 fallback 状态。
- 商品数据来自 `mock-data/`，用于比赛演示和功能闭环验证。
- Web/PWA 已注册 service worker 缓存 app shell；离线时可打开页面骨架，涉及登录、识别、比价、推荐的动态数据仍需要后端 API 在线。
- 后续真实平台数据只通过 `official_api` 或授权样例数据扩展，不做非授权数据抓取。
