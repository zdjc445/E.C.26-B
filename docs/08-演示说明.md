# 演示说明

## 项目一句话介绍

拍一下商品，AI 帮你识别它、生成下一步导购建议、跨平台比较候选价格，并通过自然语言追加筛选快速收敛到可信购买建议。

## 本机演示入口

```text
后端：http://localhost:8080
Swagger：http://localhost:8080/swagger-ui.html
前端：http://localhost:5173
```

启动方式见根目录 `README.md`。

## 标准操作路径

1. 打开 Web/PWA 演示端。
2. 注册或登录账号。
3. 点击“打开相机”完成浏览器相机预览，也可以点击“示例图”生成一张吹风机 mock 图片。
4. 点击“上传并识别”，展示类目、品牌、关键词、属性和置信度。
5. 查看动态建议卡片，如“查看同款低价”“只看官方旗舰店”“评价 4.8 分以上”。
6. 点击“只看官方旗舰店”或输入自然语言筛选：

```text
1000 元以内的黑色款，要评价 4.8 分以上，只看官方
```

7. 切换综合、低价、销量、好评排序，观察推荐列表刷新。
8. 勾选 2-4 个商品并点击“生成比价”，展示平台最低价、平台均价、平台商品数和横向商品对比表。
9. 点击“收藏”演示个性化入口，再点击“生成推荐”，展示推荐结论、理由、风险和 evidence。

## 3-5 分钟视频脚本

| 时间 | 内容 | 讲解重点 |
| --- | --- | --- |
| 0:00-0:30 | 项目定位 | 从商品搜索升级为购物决策 Agent |
| 0:30-1:10 | 拍照识物 | 浏览器相机/文件上传到服务端，AI 计算不在客户端执行 |
| 1:10-1:50 | 建议卡片 | 卡片基于识别结果和当前上下文生成，不是固定按钮堆叠 |
| 1:50-2:40 | 自然语言追加筛选 | 文本解析成结构化 filters，列表实时刷新 |
| 2:40-3:30 | 比价、对比与排序 | 平台最低价、均价、商品数、商品对比表、低价/销量/好评排序 |
| 3:30-4:30 | Agent 推荐 | 推荐理由必须附带价格、匹配、评价、历史价格 evidence |
| 4:30-5:00 | 工程与合规 | mock/sample dataset，保留 official API 扩展口，不做非授权数据抓取 |

## 推荐演示话术

```text
这不是单纯的以图搜图，而是把“识别 - 检索 - 比价 - 决策”串成一条可解释链路。
用户拍照后，服务端识别商品属性并生成建议卡片；用户可以点击卡片，也可以继续输入自然语言条件。
系统会把“1000 元以内、黑色、评分 4.8 以上、官方渠道”等条件结构化，刷新商品列表并重新计算平台统计。
最终 Agent 不相信前端传入价格，而是基于后端 mock 数据、历史价格、评价摘要和匹配分生成带 evidence 的推荐。
```

## 兜底说明

- 默认 AI provider 为 `mock`，无 Ark API Key 时仍可完整演示；启用 Ark 后，接口会返回 provider 与 fallback 状态。
- 商品数据来自 `mock-data/`，用于比赛演示和功能闭环验证。
- 后续真实平台数据只通过 `official_api` 或授权样例数据扩展，不做非授权数据抓取。
