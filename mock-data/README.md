# Mock 数据说明

本目录存放聊天式 Mock Agent 阶段的开发与演示数据。所有数据均为人工构造示例，不代表真实平台商品、真实价格或真实用户数据。

## 文件说明

| 文件 | 用途 |
|------|------|
| `chat-agent-scenarios.json` | 聊天式 Agent 演示流程 |
| `recognition-samples.json` | 后续图片识别输出示例 |
| `products.json` | 推荐卡片使用的演示商品 |
| `platform-products.json` | 后续比价能力使用的演示平台商品 |

## 当前阶段使用方式

当前阶段的 Mock Agent 可参考 `chat-agent-scenarios.json` 返回固定追问卡片和推荐卡片：

- 用户发送文字或图片后，返回追问卡片
- 用户点击追问选项后，返回推荐卡片
- 推荐卡片中的平台名称统一带 `-mock` 后缀
- 语音按钮仅作为客户端占位，不读取本目录数据

## 后续扩展

- 增加更多聊天场景
- 扩充商品类型和价格区间
- 增加搜索结果卡片和比价卡片演示数据

## 约束

- 不包含真实用户数据
- 不包含爬取数据
- 不包含真实密钥、Token 或个人信息
- 不把 Mock 数据描述为真实平台数据
