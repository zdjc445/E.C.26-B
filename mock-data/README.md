# Mock 数据说明

本目录存放聊天式 Mock Agent 阶段的开发与演示数据。所有数据均为人工构造示例，不代表真实平台商品、真实价格或真实用户数据。

## 后端运行时 Mock 商品

后端运行时使用 `MockProductSourceProvider` 内置 5 品类 × 3 平台 × 4 商品（共 60 个）：

| 品类 | 平台 | 价格区间 | 关键差异 |
|------|------|----------|----------|
| 运动鞋 | 京东 / 拼多多 / 淘宝-mock | 169 - 459 元 | 含耐克 / 阿迪达斯 / 新百伦 / 李宁品牌 |
| 耳机 | 京东 / 拼多多 / 淘宝-mock | 79 - 458 元 | 含索尼 / 森海塞尔 / 小米 / 华为品牌 |
| 吹风机 | 京东 / 拼多多 / 淘宝-mock | 59 - 349 元 | 含戴森 / 飞利浦 / 松下品牌 |
| 背包 | 京东 / 拼多多 / 淘宝-mock | 69 - 299 元 | 含耐克 / 阿迪达斯 / 新百伦 / 小米品牌 |
| 智能手表 | 京东 / 拼多多 / 淘宝-mock | 179 - 2899 元 | 含苹果 / 华为 / 小米品牌 |

每个品类故意分布在低/中/高价位段，并故意包含部分非官方渠道、评分偏低的商品以触发推荐解释的「不足」分析。

平台名固定为：

- `京东-mock`
- `拼多多-mock`
- `淘宝-mock`

## 商品字段

`ProductOffer` 字段：

| 字段 | 说明 |
|------|------|
| `productId` | 平台前缀 + 序号 |
| `title` | 商品标题，含品牌、颜色、关键属性 |
| `platform` | `京东-mock` / `拼多多-mock` / `淘宝-mock` |
| `price` | 当前价 |
| `originalPrice` | 原价（用于划线） |
| `shopName` | 店铺名（含品牌前缀） |
| `imageUrl` / `productUrl` | 当前为空，后续接入图片资源后补齐 |
| `rating` | 4.1 - 4.9 |
| `sales` | 销量数（影响排序信号） |
| `tags` | 自营 / 官方 / 旗舰店 / 爆款 / 性价比 / 透气 / 防水 / 长续航 等 |
| `reasons` | 评分时生成的命中理由（由 `RecommendationScorer` 填充） |
| `score` | 评分时生成 |
| `brand` | 商品品牌，规则解析中可命中品牌过滤 |
| `priceHistory` | 5 点近期价格走势，演示用，不代表真实历史 |
| `matchedPreferences` | 评分时记录的命中偏好 key：`low_price / official_store / fast_delivery / high_rating / high_sales / budget_match / brand_match / min_rating_met` |

## 演示场景覆盖

后端 Mock 数据故意覆盖以下演示场景：

- **预算过滤：** 任何品类都有低/中/高三档商品。
- **颜色过滤：** 每个品类至少有黑、白、蓝、粉等多种颜色。
- **品牌过滤：** 7 个品类支持 11 个常见品牌（中英文均可命中）。
- **官方店 / 自营：** 每平台至少含 1 个官方/自营商品。
- **配送快：** 京东-mock 的 fast_delivery 命中。
- **高评分：** 至少 1 个 ≥ 4.8 的商品。
- **高销量：** 至少 1 个 ≥ 10000 销量的商品。
- **不足分析：** 至少 1 个 < 4.5 评分的商品，用于推荐解释生成 weaknesses。
- **超预算：** 50 / 30 元可触发空商品 + 空比价占位。

## 约束

- Mock 数据均为人工构造示例。
- 不包含真实用户数据。
- 不包含爬取数据。
- 不包含真实密钥、Token 或个人信息。
- 不把 Mock 数据描述为真实平台数据。
- 真实平台接口接入后，Mock 数据仍作为演示模式和降级数据。
