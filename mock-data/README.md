# Mock 数据说明

本目录存放开发与演示用的模拟数据。当前阶段仅包含极少量自造示例，后续将扩展为完整演示数据集。

## 文件说明

| 文件 | 用途 |
|------|------|
| `recognition-samples.json` | AI 识别结果示例 |
| `products.json` | 模拟商品数据 |
| `platform-products.json` | 模拟多平台同款商品 |

## 使用方式

后端在 mock 模式下加载此目录的数据。所有数据均为人工构造示例，不涉及真实用户数据或爬取数据。
